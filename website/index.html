Download

Windows

Run the installer and finish the steps. Zunn opens in your tray. If Windows shows a SmartScreen notice, choose More info, then Run anyway. The portable file needs no installation.

Linux

Extract the archive, then run the app inside it.

tar -xzf Zunn-Linux.tar.gz
cd Zunn
chmod +x zunn
./zunn

If it reports a sandbox error, start it with --no-sandbox. On Wayland the hotkey may not work, so click the tray icon instead.

03

Help

The essentials. Press ? inside Zunn to see this guide there.

Shortcuts

Show or hide ZunnAlt + Space
HideEsc
Switch tabsCtrl + 1 to Ctrl + 4
SearchCtrl + F
Add to the current tabCtrl + N
SettingsCtrl + ,
Help?
Open the selected cardEnter
Open its folderShift + Enter
Open a terminal thereCtrl + Enter

On a Mac, use Cmd instead of Ctrl. You can change the main hotkey in Settings.

Add a project

On the Projects tab press Ctrl + N, or drag a folder or file into the window. Name it and choose how it opens: in your editor, with the system default, or with a program you pick. Right-click any card for more actions, and drag cards to reorder them.

Add an app

On the Apps tab press Ctrl + N and start typing in Find installed app. Choose a result and the path and icon are filled in for you. You can also drop a program into the window.

Search and shortcuts

Type a web address to open it. Type anything else to search your projects, apps and links, or the web. Begin with a shortcut to search one site.

!yt lofi hip hop
!gh launcher
!wiki aurora
!maps coffee

Included: !yt !gh !gpt !wiki !ddg !bing !amazon !maps. Add your own in Settings.

Notes and alarms

Notes save as you type. Tap the clock on a note to choose a future date and time. When it arrives, Zunn comes forward and rings until you dismiss it.

Settings and data

Open Settings with the gear or Ctrl + , to change the hotkey, theme, transparency, text size, editor and background. You can also export or import your data.

Questions

Zunn vanished. Did it close?

No. It hides when you click away. Press the hotkey or click the tray icon. Choose Quit in the tray menu to exit.

The hotkey does nothing.

Another app may already use Alt + Space. Pick a different one in Settings.

An app is missing from the list.

Drop its shortcut or program into the Add App window.

Where is my data stored?

In one file on your computer. Settings, Data, Show file will take you there.
